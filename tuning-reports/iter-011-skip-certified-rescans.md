# 调优报告 iter-011：跳过已认证频道的巡回重扫描

- 日期：2026-09-12
- Git commit：`390bd58`（代码）；报告随后续 docs 提交入库
- 基准集：benchmark v2（DEV：p3 60 / p4 100，vs iter-009b 基线配对）

## 动机（数据来源：iter-009b 相位分解）

扫描循环对**未清除**频道逐点测量——包括已认证（区域半径 ≤ 19.5 m、
等待路线清除停靠）的频道。p4 的 25 点巡回中，频道认证后到其清除停靠
执行前的每个剩余扫描点都在为它支付 6 s 的无信息重测（wasted_cov_meas
119.2 次/案例的一部分）。

## 调优手段

`python-code/simulator_client.py`（扫描循环，~10 行）：

跳过 `state.cleared` 之外的另一类频道——`pending_clear` 或
`region_radius ≤ SAFE_CLEAR_RADIUS`。安全性：认证 = 最小包围圆半径
≤ 19.5 < 20 ⇒ 清除必成功（数学保证，与 iter-004 同口径）；额外方位
不可能改进已认证频道。清除停靠仍由 `_schedule_clears` 正常插入。

## 调优后性能（同 seed 配对）

| 指标 | p3（n=60） | p4（n=100） |
|---|---|---|
| 清除率 | 60/60（100%） | 100/100（100%） |
| 虚拟时间均值差 | **−7.3 s**（std 17.0；17 改善/**0 恶化**） | **−98.3 s**（std 85.5，1.15σ；93 改善/1 恶化，符号检验 p≈1e-21） |
| P95 | 4947.9（持平） | 8622.0 → **8563.7** ✓ |
| CVaR90 | 4975.4（持平） | 8681.1 → **8594.1** ✓ |
| 测量数均值 | 147.8 → 146.8 | 354.7 → 338.1（−16.6） |

唯一恶化个案（seed 1310078，+152.8 s）：早停触发时序受测量集变化扰
动，属噪声型个案；总量 93/1 方向压倒性。

**STRATIFIED 63/63 全部清除**（21 个 (N, d) 配置 × 3 seed，含 n=16
d=15 极端构成；多数配置较 iter-008 时代同 seed 改善 100~300 s）。

## 准入判定

清除率不降 ✓；p4 均值 −98.3 s 显著（1.15σ + 方向一致性 p≈1e-21）✓；
P95 与 CVaR90 均改善 ✓。**通过，正式合入。**

回到自主调优循环后的首个正收益：纯测量节省（p4 −16.6 次/案例），
无移动变化、无风险。当前 p4 剩余结构：覆盖巡回 ~64%（认证下限）、
清除绕行 ~22%、收尾 ~13%。
