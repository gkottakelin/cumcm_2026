# 基准集定义（benchmark v2）

模拟器于 commit `9f1f731` 按题面附件校准（P4 源数 10-16 随机、定向数
1..N-1 随机、`/clear` 不切频道、初始频道 1、`no_target_in_range`、
svd 保留 2 位小数、幂等 request_id 等）。**v1 基准（固定 16/5 场景）
自此作废**，仅作历史记录；v1 的 p3 数据口径与 v2 接近（p3 生成规则只
改了默认源数，回归中本就随机 10-16），但为统一仍以 v2 重采为准。

## 三层测试体系（依据 optimization-directions-after-simulator-alignment.md）

### DEV（开发集，允许调参）

| 项 | 值 |
|---|---|

| 命令 | `uv run python python-code\run_local_regression.py --problem 4 --cases 100 --seed 910000 --output out\bench\v2-dev-p4.json`（p3 同理 `--problem 3 --cases 60`） |

### TEST-v2（冻结集，方案定稿前禁止用于任何参数选择）

| 项 | 值 |
|---|---|
| 组成 | p3/p4 各 50 案例 |
| 命令 | `--seed 720000 --cases 50` |
| 实际种子 | p3: 1020000..1020049；p4: 1120000..1120049 |
| 使用规则 | 仅在候选方案定稿后做一次性评估；结果一旦用于选择即失去冻结资格，须换 seed 重建 |

### STRATIFIED（分层压力集）

| 项 | 值 |
|---|---|
| 组成 | P4：N ∈ {10..16} × 定向数 d ∈ {1, floor(N/2), N-1}，共 21 个配置 × 每配置 3 个 seed |
| 命令 | `uv run python python-code\run_local_regression.py --problem 4 --cases 3 --seed 9200NN --source-count N --directional-count d --output out\bench\v2-strat-nNdD.json`（NN 为配置序号） |
| 用途 | 检验"确保清除"在最不利构成下的鲁棒性；报告按 N 与 d 分层 |
| 附注 | 困难几何条件（源贴近圆域边界、接收半径贴近 1000、发射方向贴近半平面边界）由大样本随机 + 分层构成联合覆盖 |

## 场景生成规则（v2）

- 源数：p3/p4 均 `rng.integers(10, 17)`（10-16 均匀）；
- p4 定向数：`rng.integers(1, N)`（1..N-1，两类源保证存在）；
- 其余（频道不重复、圆域均匀、半径 1000-1500、定向两侧各 90°）与题面一致。

## 统计纪律（v2）

1. 每份性能数据必须报告：全部清除率；虚拟时间均值 ± std、P50、P90、
   P95、最大值、CVaR90（最差 10% 案例均值）；移动/检测/切换/清除四类
   耗时；总路程、测量次数、失败清除次数。
2. 前后对比一律同 seed 配对，报告配对差均值与配对差 std。
3. **候选方案准入条件**：清除率不下降 ∧ 均值显著改善（≥1σ_配对差或
   方向一致性符号检验 p<0.01）∧ P95 与 CVaR90 不恶化。
4. 单案例 FAIL 先同 seed 复跑确认可复现（排除环境偶发，注意回归命令
   独占端口、禁止并行），再进入根因分析。
5. 临时探索可用任意 seed 小规模跑，其结果只用于形成假设，不得写进
   调优前后性能表。
