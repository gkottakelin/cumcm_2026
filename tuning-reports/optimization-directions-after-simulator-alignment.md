# 模拟器校准后的优化方向

更新时间：2026-09-12

## 1 结论

本轮首先依据 B 题正文、附件 1《模拟器使用说明》和附件 2《模拟器通信接口说明及编程指南》修正了本地模拟器。修正后的冒烟回归为 P3 10/10、P4 10/10 全部清除成功，但 P4 的 10 个随机案例平均虚拟时间上升到 8118.8 秒。这说明此前固定“16 个源、5 个定向源”得到的 6151.1 秒不能继续作为 P4 的代表性基准。

后续优化不应继续优先微调 `lambda`、候选点个数或 2-opt。建议依次完成：

1. 在新模拟器上重建基准和独立测试集；
2. 修复 P3 非凸 `no_signal` 信念更新和 P4 的角度误差鲁棒性；
3. 对 25 点 P4 覆盖布局进行连续证明和新口径回归；
4. 将覆盖、补测和清除统一为滚动联合规划，并复用一次停靠完成多个频道的测量。

### 2.1 场景生成规则

| 项目 | 修正前 | 修正后 |
|---|---|---|
| P3 信号源总数 | 默认 13，回归中随机 10-16 | 默认和回归均随机 10-16 |
| P3 信号源类型 | 全向 | 全向 |
| P4 信号源总数 | 固定 16 | 随机 10-16 |
| P4 定向源数量 | 固定 5 | 在 `1..N-1` 中随机，保证全向和定向两类都存在 |
| 显式压力场景 | 可指定 1-20 个源 | 只允许题面范围 10-16；P4 必须同时包含两类源 |
| 频道 | 1-20 且不重复 | 保持不变 |
| 源位置 | 半径 1800 米圆域内均匀采样 | 保持不变 |
| 有效接收半径 | 1000-1500 米 | 保持不变 |
| 定向覆盖 | 定向方向两侧各 90 度，包含边界 | 保持不变 |

题目没有公开位置、接收半径、定向数量和方向的真实随机分布。因此本地模拟器的均匀分布只是满足题面约束的一种测试分布，不能宣称复现了官方隐藏分布。正式算法验证必须补充分层压力测试，而不能只依赖默认随机样本。

### 2.2 动作和计时规则

已修正以下协议偏差：

- 成功 `/enter` 后初始位置为 `(0,0)`，测向机初始频道为 1；
- `/measure` 才会切换测向机频道，频道变化增加 1 秒；
- `/clear` 的 `channel` 只表示目标频道，不切换测向机频道，也不产生频道切换耗时；
- `/clear` 未发现目标时返回 `no_target_in_range`，耗时 3 秒；成功时返回 `success`，耗时 5 秒；
- `/measure` 无论返回 `no_signal`、`near` 还是 `direction`，检测耗时均为 5 秒；
- 运动时间为相邻合法动作位置的欧氏距离除以 5 m/s；
- `/enter` 返回 `max_virtual_duration_s=360000`、`max_real_duration_s=1200` 和 `remaining_real_duration_s=1200`；
- `/enter` 和 `/exit` 不推进虚拟时间；
- 虚拟时间最多保留 6 位小数。

附件 1 给出的计时示例已经加入自动测试，四个动作后的虚拟时刻依次为 105、111、194、199 秒。

### 2.3 检测、清除与接口规则

已补齐：

- 示向度误差保持在题面给定的有界模型内，同一频道、同一位置重复测量误差固定；
- `svd_deg` 归一化到 `[0,360)` 并保留两位小数；
- 距离不超过 5 米且处于有效覆盖角度内时返回 `near`；
- 距离不超过 20 米时可清除，包含 20 米边界，且不受定向源朝向影响；
- 坐标必须为有限数值，每个分量绝对值不超过 2000000 米；
- `channel` 接受 1-20 的整数值，也接受数值上为整数的 JSON number，例如 `1.0`；
- 未声明字段、缺失字段、嵌套位置字段、非法标识符、重复 JSON 键、请求体大小和 JSON 嵌套深度检查；
- `Content-Type`、`Content-Encoding`、404、405、409、413、415 和 500 响应；
- 成功请求的 `request_id` 幂等：相同 ID 和完全相同内容返回第一次响应，不重复执行；相同 ID 改变内容返回 HTTP 409；
- 所有业务响应包含 `accepted`、`real_timestamp_ms` 和 `virtual_time_s`；拒绝响应的 `virtual_time_s` 为 0。

本地 `/health` 和 `/state` 仍作为只读测试接口保留，不属于正式协议，也不会被正式客户端调用。官方模拟器的 25 分钟 GUI 窗口、在线登录、服务器校时、网络中断和未公开的 429 防护阈值无法在离线模拟器中等价复现；算法仍需使用 `/enter` 返回的剩余现实时间，并在正式模拟器演练中验证网络行为。

## 4 优化方向与优先级

### P0 重建可信基准

旧 BENCH 和 VAL 已参与七轮调参，而且 P4 使用固定 16/5 场景，不能再承担最终泛化评估。

建议建立三层测试：

1. `DEV`：允许调参，保留失败详情；
2. `TEST-v2`：完成方案前保持冻结，不用于选择参数；
3. `STRATIFIED`：枚举总数 `N=10..16`，P4 定向数至少覆盖 `1`、`floor(N/2)`、`N-1`，并覆盖接收半径靠近 1000 米、源靠近圆域边界、角度靠近定向半平面边界等困难条件。

每个候选方案至少报告：

- 全部清除率；
- 虚拟时间均值及配对置信区间；
- P50、P90、P95、最大值和 CVaR90；
- 移动、检测、切换、清除四类耗时；
- 总路程、测量次数、失败清除次数；
- 按源总数和定向比例分层的结果。

候选方案的准入条件应为“清除率不下降、均值显著改善、P95 或 CVaR90 不恶化”，而不是只比较均值。

### P0 修复 P3 的非凸 `no_signal` 更新

当前客户端把接收圆外部错误地表示为多个外切半平面的交集，通常得到空集并回退到旧区域。因此大量 P3 `no_signal` 信息没有真正缩小信念域。

正确更新为：

```text
P <- P \ Disk(s, 1000)
```

圆外区域是非凸集合，状态需要支持 `Polygon` 或 `MultiPolygon`。还应保存首次正观测之前的 `no_signal`；一旦后续确认该频道存在全向源，历史无信号观测即可用于排除。清除证书必须对所有连通分量的并集求最小包围圆，不能只检查最大分量或凸包直径。

工程上可使用 [Shapely](https://github.com/shapely/shapely) 完成集合差、并集和多多边形操作。

验收标准：构造单次示向度加多个 `no_signal` 的案例，确认可行域严格缩小、真实源始终位于外包集合内，并且清除失败率为 0。

### P0 将正负 1 度误差纳入 P4 决策

当前 P4 结构化探测沿“报告示向度”前进，并把后续 `no_signal` 直接解释为距离括区。定向源处在发射半平面边界附近时，1 度误差就可能使机器人走到背面，因此该推断不是严格保证。

下一视点评分也只按零误差的未来视线计算。应将最坏情况写成：

```text
max over source state, reported-angle error, signal/no-signal outcome
    posterior smallest-enclosing-circle radius
```

推荐保留一个可证明安全的区间外包状态，并可并行维护粒子或采样状态用于效率评分。P4 状态至少应包含位置、源类型、发射方向和接收半径。`no_signal` 是“超出半径或位于背面”的析取约束，不能按 P3 规则更新。

需要严格外包时可采用 [IBEX](https://github.com/ibex-team/ibex-lib) 的区间与收缩器；近似动作选择可用采样，但不得用近似集合签发清除证书。

### P1 验证 25 点 P4 覆盖布局

当前 P4 为 25 个方格点加 4 个极点，共 29 点。优先测试以下 25 点候选：

- 中心 1 点；
- 半径 960 米内环 8 点；
- 半径 1850 米外环 16 点；
- 中心和内环优先，外环随后形成闭合巡回。

其全向保底覆盖最坏距离为：

```text
sqrt(1800^2 + 960^2 - 2*1800*960*cos(22.5 deg)) = 984.21 m < 1000 m
```

完整最近邻路线由约 21.35 km 降为 17.82 km，理论路程下降约 16.5%。此前离线密网格检查未发现定向覆盖违反点，但这仍然只是数值证据；旧模拟器上的时间收益也必须在本轮修正后的分布和计时规则上重新测量。

最终采用前应完成连续证明。可利用旋转对称性缩小基本区域，或构造半径 980 米圆的平面排列，逐单元验证附近扫描点凸包包含目标位置。[CGAL](https://github.com/CGAL/cgal) 的圆弧排列和精确几何适合生成独立证书程序。

### P1 覆盖定位清除联合滚动规划

当前总时间约 78% 来自移动，覆盖完成后的定位和清除仍产生很长的专程路线。单独优化 2-opt 只能重排既有目标，无法消除不必要的停靠。

应把候选动作统一为：

```text
扫描覆盖点
补测一个或多个频道
前往可证明安全的清除点
```

每次到达一个位置后，批量评估所有未清除频道，优先复用当前停靠点。动作评分同时考虑新增路程、检测时间、切换时间、多个频道的信念域缩减和未来清除路程。采用 2-4 轮滚动重规划即可，不必一次求解整个随机任务。

[Cautious Greedy Strategy](https://tokekar.com/pubs/vanderhook2014cautious.pdf) 直接研究了方位定位中移动与测量耗时的联合目标；[Active Sensing for Bearing-Based Target Localization](https://arxiv.org/abs/2311.10221) 从信息量角度优化传感器运动；[Informative Path Planning with Limited Adaptivity](https://proceedings.mlr.press/v238/tan24a.html) 支持使用少量重规划轮次平衡自适应收益与计算成本。

小规模滚动路径子问题可以用 [OR-Tools](https://github.com/google/or-tools) 建立 TSP、VRP 或 prize-collecting 基准。正式客户端可继续使用轻量启发式，OR-Tools 主要作为离线最优性对照和参数生成器。

### P2 连续证书与安全清除

5 米网格加安全裕量适合筛选方案，但不是连续数学证明。每个覆盖方案都应附带：

- 明确的连续命题；
- 解析证明、精确几何证书或区间分支定界证明；
- 独立的更密网格反例搜索；
- 对角度误差、接收半径下界和浮点舍入的敏感性测试。

清除条件统一使用最小包围圆半径 `R(P) <= 20-epsilon`，不以多边形直径小于 40 米替代。`epsilon` 应覆盖数值误差；任何启发式粒子云、均值位置或协方差椭圆都只能用于动作排序，不能直接触发安全清除。

### P2 小收益快速项

- P3 若已经检测并清除 16 个不同频道，可安全提前结束；若不足 16，仍必须完成覆盖证书。
- P3 六边形覆盖环半径可由 1150 米试降至约 1125 米，预计只节省约 162 米路程，优先级低于信念域和联合规划。
- 在同一位置连续检测时，可优化频道顺序减少切换，但收益上限通常只有数十秒。
- 将清除安全半径阈值、最终兜底阈值和论文符号统一，并明确浮点裕量，避免一处使用 19.5 米、一处使用 20 米。

## 5 推荐迭代计划

### Iteration 008 新基准与布局

1. 固化修正后的模拟器版本和随机种子清单；
2. 建立 DEV、冻结 TEST-v2 和分层压力集；
3. 重跑当前 29 点基线；
4. 实现 25 点候选，仅改变覆盖布局；
5. 完成至少 300 个配对案例；
6. 以清除率、均值、P95 和 CVaR90 决定是否替换布局。

### Iteration 009 正确性修复

1. 重写 P3 非凸 `no_signal` 集合更新；
2. 补齐历史无信号观测；
3. 将正负 1 度误差加入下一视点的最坏情况评分；
4. 删除或改写无法证明的 P4 距离括区规则；
5. 为真实源始终位于信念外包内建立性质测试。

### Iteration 010 联合规划

1. 在覆盖途中插入低增量成本的补测和清除；
2. 一次停靠批量服务多个频道；
3. 使用 2-4 轮滚动重规划；
4. 用 OR-Tools 离线下界评估启发式损失；
5. 最后再优化局部路径和频道顺序。

## 6 决策原则

1. 题面明确约束优先于单次官方演练现象；一次演练恰好出现 16/5，不能推导官方分布固定为 16/5。
2. 本地随机分布只能用于算法开发，分层极端案例才用于检验“确保清除”的鲁棒性。
3. 数值网格零违例只能作为候选筛选，不能在论文中表述为解析证明。
4. 任何能够触发清除的判断都必须来自保守外包集合；概率模型只负责提速。
5. 先修正确性和评估口径，再比较秒级微调，否则优化结论不可复现。
